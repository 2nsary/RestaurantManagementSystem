# Restaurant Management System 🍽️

An ERP-style restaurant management system developed to manage restaurant operations and workflows efficiently.

## Features
- Order management
- Customer handling
- Restaurant workflow organization
- Database integration
- Structured backend architecture
- Multi-module system design

## Technologies Used
- Java
- JavaFX
- SQLite
- CSS

## Project Structure
- Organized application architecture
- Database connectivity
- Multiple management modules
- Responsive desktop interface

## Purpose
This project was built to improve software engineering and backend development skills through building a real-world management system.
